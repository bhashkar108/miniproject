Problem Statement 02 / 10

The Real Challenges Faced by Students Today

Millions of ambitious students struggle with English communication, study fragmentation, and privacy risks.

🗣️

English Speaking Anxiety

Students hesitate to speak due to fear of judgement, lack of conversational partners, and zero constructive real-time feedback.

  • ▪ Hesitation in job interviews & vivas
  • ▪ Grammatical confusion without friendly explanations
  • ▪ Expensive spoken English institutes
📚

Scattered Study Tools

Learning materials are scattered across PDF readers, quiz portals, document compressors, and generic chatbots.

  • ▪ Generic chatbots hallucinate without syllabus context
  • ▪ Manual document compression breaks file formats
  • ▪ Static quiz sheets without instant answer checks
🔒

Privacy & Accessibility Gaps

Students are forced to upload personal documents and certificates to shady third-party web tools.

  • ▪ Data leakage of IDs and academic marksheets
  • ▪ Poor native language support (Hindi / Regional)
  • ▪ Rigid templates that do not respect student materials

Document & Math Tools 06 / 10

Smart Doc Studio & Equation Grapher

Client-side document manipulation and interactive mathematical curve exploration.

📄

Smart Doc: In-Browser Optimizer

Process academic documents locally without uploading sensitive files to external cloud servers.

  • ✦ Direct Camera Capture: Full-screen document scanning with camera flash and preview.
  • ✦ Persistent Adjustments: Real-time 90° rotation, 4-sided edge cropping, and format conversion (PDF, PNG, JPEG).
  • ✦ Target File Size Compression: Dial in target KB/MB sizes for exam upload portals.
  • ✦ Side-by-Side Comparison: Compare original and processed copy with sync zoom and full-screen preview.
📈

Equation Graph Visualizer

Mathematical clarity through interactive graphing and OCR handwriting recognition.

  • ✦ Multi-Function Plotting: Compare two curves simultaneously (e.g., sin(x) and cos(x)) on an SVG grid.
  • ✦ Automatic Intercepts: Computes axis intercepts, local extrema, and curve intersections in real time.
  • ✦ Image / PDF OCR: Snap a photo of handwritten equations to automatically populate graph functions.

Architecture 08 / 10

Technology Stack & Architecture

Built with modern web standards, client-side speed, and robust TypeScript engineering.

⚡

Frontend Core

React 19, TypeScript, Vite, TailwindCSS, Lucide Icons, and Wouter for lightning-fast routing.

🎙️

Speech & Audio

Web Speech API (Recognition + Synthesis), Web Audio API, Canvas 24-band equalizer, standalone vanilla JS bundle.

📄

Local Processing

PDF-lib, PDF.js Worker, HTML5 Canvas API, Mathjs parser for secure client-side calculations.

🛡️

Backend & Privacy

Node.js Express API, Argon2 encryption, SQLite / Session Auth, guest mode with local storage persistence.
